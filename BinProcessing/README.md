# BinProcessing

A Swift Package for card BIN (Bank Identification Number) processing, used by MobileSDK in the Paydock iOS SDK.

## Overview

`BinProcessing` provides functionality for BIN-related operations. The package is consumed by the main MobileSDK target.

## Usage

Add `BinProcessing` as a dependency of your target. From MobileSDK, import the module:

```swift
import BinProcessing
```

## Structure

- **Sources/BinProcessing**: Library source code
- **Tests/BinProcessingTests**: Unit tests
